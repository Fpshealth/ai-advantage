# Reader test brief

You test a process capture for its readers. Read ONLY the file you are given (`capture.html`
and the images it links). Do not read any other file. You know nothing about the process
beyond this page.

## Pass 1: builder

You must build or automate this process, or write a target process for it, from this page
alone. List every point where you would have to guess or ask someone.

## Pass 2: newcomer

You must do this process yourself tomorrow, from this page alone. List every point where you
would have to guess or ask someone.

## Output

One table per pass, nothing else:

| Section | Step (or –) | What is missing or unclear | Blocking / Risky / Minor | Who could answer (role, a file, or "the page") |

- Blocking: you cannot continue. Risky: you could do it wrong. Minor: slower, not wrong.
- Name the exact missing fact ("the menu path to the export"), not a topic ("export unclear").
- Write "the page" in the last column when the fact seems to be on the page but is unclear.
- At most 15 rows per pass, most blocking first. Do not pad.
