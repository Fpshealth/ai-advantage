How the nightly photo backup works

The shared laptop copies new photos to an external disk every night, so a lost laptop loses at most one day of photos. A backup script is a small program on the laptop that copies every photo changed since its last run. The schedule is a line in the laptop's task list that starts the backup script at 02:00 each night. The backup disk is the external drive that holds the copies, and the log file is a text file where the backup script writes one line per run.

One night

What happens on one real night? On 3 November the schedule started the backup script at 02:00, and it copied 14 photos in 9 seconds (log file, line 212).

The parts

Where does each part live? The backup script and the schedule live on the laptop; the copies live on the backup disk.

Checking it worked

How do I know last night worked? Open the log file and read the last line: it names the date and the number of photos copied.
